# TALENT — Next-Gen Student Work Platform & School Cooperative

A modern, responsive React web application inspired by Hungarian student cooperatives (such as *euDiákok* and *Y Diák*), elevated with contemporary UI/UX, paperless flows, international student readiness, and dynamic earnings calculation.

## 🚀 Key Features

1. **Student Job Board & Faceted Filters**:
   * Filter by Shift (Morning, Afternoon, Evening, Weekend, Night, Flexible)
   * Filter by City (Budapest, Debrecen, Szeged, Győr, Pécs, Remote)
   * Toggle: **English Only (No Hungarian required)** for international students
   * Toggle: **Age 16-17 (High School Students)**
   * Toggle: **Home Office / Remote**
   * Real-time hourly wage slider (Ft / hr and EUR)

2. **Interactive Student Wage & Tax Calculator**:
   * Simulates Hungarian School Cooperative tax benefits
   * **Under 25 SZJA Tax Exemption**: 0% personal tax deduction (Gross = Net)
   * Sliders for hourly wage and weekly hours
   * Instant monthly net projection into student bank accounts

3. **Fast 2-Step Application Modal**:
   * Step 1: Student status verification, university, phone
   * Step 2: Schedule availability picker & CV drop

4. **Detailed Job View Modal**:
   * Full role descriptions, student contract terms, requirements, shift perks

5. **Student Portal & Dashboard**:
   * View live application statuses (*Under Review*, *Interview Scheduled*)
   * Paperless contracts checklist (e-signed agreements, Neptun certificates)
   * Shift schedules and timesheet logging

6. **Employer / B2B Section ("Hire Students")**:
   * Highlights enterprise advantages (0% employer payroll tax / szocho, zero severance liability)
   * Instant staffing quote request form
   * "Post a Job" employer modal

7. **Multilingual Ready**:
   * English base interface
   * Language switcher bar (English, Hungarian, German, Ukrainian) ready for Google Translate or i18next.
